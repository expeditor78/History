# Исходники объяснений истории

- `11.md` — связное объяснение основной логики §11; сверено с печатными с.106–114 учебника по ссылке внутри файла. Дополнительные определения сверены с относящимися к ним страницами этого же учебника. Это не выполнение всех заданий параграфа.
- `11-reports.md` — пять коротких устных докладов по пяти пунктам учебника. Минута — ориентир, а не измеренное время чтения.
- Отображаемая версия: `site/p/11.html`. Текст прошёл отдельные исторический и редакторский проверяющие прогоны ИИ; это не независимая экспертиза человека и не проверка реального усвоения учеником.

Изменения исходника надо переносить в страницу и менять версию кеша `site/sw.js`. Старый корневой `build.py` пока не синхронизирован с вручную добавленными страницами: он полностью удаляет `site/`; не запускать его для этой правки.
