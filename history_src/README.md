# Краткие пересказы — текущая версия курса

- `briefs/*.json` — исходники **всех 21 страниц** истории, включая §11. Внутренние id файлов прежние; номера и названия параграфов и всех пронумерованных пунктов — из учебника. Сдвоенные §14—15 и §16—17 не перенумерованы по id.
- Формат: короткий пересказ всего параграфа, без дублирующих докладов и длинных вступлений. `check_questions`, `heading_evidence` и `limits` — проверочные данные, не дополнительные блоки для ученика.
- `brief-review-manifest.json` — хэши принятого текста, источник, объём, число пунктов и результаты двух отдельных проверяющих ролей ИИ. Это не независимая экспертиза человека и не измерение понимания ребёнком.
- На странице можно читать по пунктам или открыть весь пересказ. Прогресс и прежние результаты тестов сохранены. Старый тест находится в закрытом блоке «Тест по полному параграфу учебника»: он охватывает полный учебник, а не только сокращённый текст.

Пересборка текущей версии (Python 3, `beautifulsoup4`):

```sh
python3 history_src/render_brief.py
```

Можно передать конкретные `briefs/*.json` аргументами. Скрипт сохраняет оболочку и тесты, не удаляет `site/`, обновляет названия ссылок и офлайн-кеш. `site/brief-nav.js` — навигация короткой версии; приложение по-прежнему использует прежний ключ результатов, а позиция чтения хранится отдельно.

**Не запускать корневой `build.py`: он удаляет весь `site/`.**

# Исходники объяснений истории

- `11.md` — связное объяснение основной логики §11; сверено с печатными с.106–114 учебника по ссылке внутри файла. Дополнительные определения сверены с относящимися к ним страницами этого же учебника. Это не выполнение всех заданий параграфа.
- `11-reports.md` — пять коротких устных докладов по пяти пунктам учебника. Минута — ориентир, а не измеренное время чтения.
- Отображаемая версия: `site/p/11.html`. Текст прошёл отдельные исторический и редакторский проверяющие прогоны ИИ; это не независимая экспертиза человека и не проверка реального усвоения учеником.

Изменения исходника надо переносить в страницу и менять версию кеша `site/sw.js`. Старый корневой `build.py` пока не синхронизирован с вручную добавленными страницами: он полностью удаляет `site/`; не запускать его для этой правки.

## Остальные уроки: проверяемые исходники и сборка

- `lessons/*.json` — канонические исходники 20 остальных страниц курса. §11 сохраняется отдельно в прежних Markdown-файлах и не пересобирается этим скриптом.
- `review-manifest.json` — фактические хэши принятого текста, диапазоны источника и заключения двух отдельных проверяющих ролей ИИ. Это не независимая экспертиза человека и не измерение понимания ребёнком.
- Каждый урок содержит связное объяснение участников, причин, действий и последствий, короткие самостоятельные доклады, вопросы своими словами и мини-тест с объяснениями. Минута для доклада — ориентир, не измеренный хронометраж.
- Там, где учебник не раскрывает механизм или содержит неоднозначность, предел объяснения сохранён; недостающие факты не достраиваются по памяти. Диапазон извлечения иногда включает задания/итоги главы или соседний заголовок — это не дополнительные пункты самого параграфа.
- Поле `limitations` в JSON сохраняет авторскую заметку на момент подготовки версии. Актуальное принятие определяется `review-manifest.json`. Сборщик оставляет содержательные пределы источника, но не выводит временные служебные пометки о незавершённом аудите в урок для ученика.

Пересборка только этих 20 уроков (Python 3 и пакет `beautifulsoup4`):

```sh
python3 history_src/render.py
```

Можно передать один или несколько JSON-файлов аргументами. Скрипт не удаляет `site/`, сохраняет внешнюю оболочку страниц, не меняет русский язык, карты, Android и §11, обновляет версию/состав офлайн-кеша. После изменения текста нужны повторные фактологическая и редакторская сверки актуальной версии; старое заключение не переносится на неизвестный новый текст. Правильные варианты тестов перемешиваются воспроизводимо, без циклической последовательности букв.

**Не запускать старый корневой `build.py`: он удаляет весь `site/` и не синхронизирован с вручную добавленными страницами.**
