# История и русский язык, 7 класс — по-человечески

Откройте `site/start.html`, чтобы выбрать предмет. В разделе «История Нового времени» (`site/index.html`) есть 21 краткий пересказ, тесты, лента времени и видеоразборы.

- Для публикации нужен статический хостинг, например GitHub Pages: публикуйте содержимое `site/`.
- Для текущей версии «Истории Нового времени» см. `history_src/README.md`. **Не запускайте старый `build.py`: он удаляет весь `site/`.**

## Раздел «История России»

- `site/russia/index.html` — 3 главы, 29 уроков по §§ 1–48 учебника Мединского и Торкунова. Сдвоенные параграфы оставлены вместе, как в учебнике.
- В каждой главе — краткий итог; в каждом уроке — пересказ по пунктам, печатные страницы и вопрос с раскрываемым ответом. Позиция в уроке запоминается в браузере.
- Исходники — `russia_src/1.json`–`russia_src/3.json`. После правок запустите `python3 build_russia.py` из корня проекта: он пересоберёт `site/russia/` и обновит общий офлайн-кеш без дополнительных пакетов. Исходный PDF не входит в сайт.

## Раздел «Русский язык»

- Исходники — `rus_src/` (`content1.py`–`content3.py` — тексты правил, тесты, практикум; `rus.css`, `rus.js` — оформление и логика).
- Сборка: `python3 build_rus.py` — пересоздаёт только `site/rus/` и обновляет `site/sw.js` (офлайн-кеш).
- Что внутри: 9 тем (язык и норма, причастие, деепричастие, наречие, категория состояния, предлог, союз, частица, междометие), мини-тест в каждой теме, итоговый тест (48 вопросов), практикум (алгоритм Н/НН, пунктуация, поиск ошибок, ударения), шпаргалка и термины.
- Прогресс хранится в браузере отдельно от истории (`rus7.v1`).

## Android-приложение

Папка `android/` — оболочка на WebView, которая берёт сайт из `site/` и работает без интернета (кроме видео).

- Сборка в GitHub: Actions → **Build Android APK** → Run workflow; готовый `app-debug.apk` будет в Artifacts.
- Локально: `cd android && gradle assembleDebug` (JDK 17, Android SDK 34).
- После изменения сайта пересоберите APK, чтобы обновить содержимое.

Если сайт открывается по своему домену с заголовком Content-Security-Policy, добавьте `frame-src https://www.youtube-nocookie.com`, иначе видео будут заблокированы.
