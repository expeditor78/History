# История Нового времени, 7 класс — по-человечески

Статический сайт для занятий: 21 шпаргалка, интерактивные тесты, лента времени, прогресс в браузере.

- Сайт — папка `site/` (открыть `site/index.html`).
- Пересборка из выгрузки Notion: `python3 build.py && cp dist_src/* site/`.
- Деплой: GitHub Pages, воркфлоу `.github/workflows/pages.yml`.
