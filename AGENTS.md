# History · инструкции для агента

- Это статический сайт для 7 класса. Вход — `site/start.html`; «История Нового времени» — `site/index.html`; «История России» — `site/russia/index.html`; «Русский язык» — `site/rus/index.html`. Android берёт содержимое `site/` как assets.
- Правь «Историю России» в `russia_src/1.json`–`russia_src/3.json`, а не в сгенерированных HTML. Каждая глава содержит итог и вопрос; каждый урок — номер, название, печатные страницы, пронумерованные пункты и вопрос с раскрываемым ответом. Всего 3 главы, 29 уроков по §§ 1–48; сдвоенные параграфы не разделяй. Если работаешь из полной папки «учебник», исходный PDF лежит в `../История/7_klass_._Istoriya_Rossii.pdf`.
- Пересборка курса: `python3 -B build_russia.py` из корня репозитория. Команда обновляет `site/russia/` и `site/sw.js`, внешних пакетов не требует. Сохраняй `dist_src/start.html` и `site/start.html` согласованными при правках экрана выбора.
- **Не запускай старый `build.py`: он удаляет весь `site/`.** Для текущей «Истории Нового времени» см. `history_src/README.md`; для русского языка — `build_rus.py` и `README.md`.
- Навигация по пунктам общая с «Историей Нового времени» (`site/brief-nav.js`). У уроков России отдельные идентификаторы `russia-*`, чтобы не смешивать сохранённую позицию двух курсов. Не ломай чтение всех пунктов без JavaScript.
- Проверка после правок: пересобери курс, выполни `git diff --check`; для проверки в браузере запусти `python3 -m http.server 8000 --bind 127.0.0.1 --directory site` и открой `/start.html`. Проверь переходы, режимы «По пунктам»/«Весь пересказ», раскрытие ответа и офлайн-доступ. При первой сдаче сверены 29 уроков и 143 заголовка по PDF, проверены ссылки, повторяемость сборки, мобильный вид, сохранение позиции и офлайн-чтение в Chromium.
